Para el profesorado:
Antes de jugar, acordad qué significa cada paso. Por ejemplo:
  • Paso 1 = avanzar una casilla
  • Paso 2 = girar a la derecha
  • Paso 3 = avanzar una casilla
  • Paso 4 = girar a la izquierda
El objetivo es comprender que el orden de las instrucciones cambia el resultado.
